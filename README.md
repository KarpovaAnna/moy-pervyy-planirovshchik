# Мой первый планировщик — Ритм недели

Недельный планировщик на русском языке: задачи, категории, повторения, выполнение, перенос, поиск, статистика и резервные копии.

## Запуск

Откройте `index.html` в браузере. Сохраните рядом `style.css` и `script.js`. Интернет, установка зависимостей и сервер не требуются для локальной версии. Публичная версия размещается через GitHub Pages из корня ветки `main`.

## Данные

Имя выбирает локальный профиль. Данные хранятся в Local Storage этого браузера, не отправляются на сервер и не синхронизируются между устройствами. Вход без пароля не защищает профиль от других пользователей того же браузера. Для переноса и резервного копирования используйте экспорт и импорт JSON.

Локальная версия и GitHub Pages имеют разные хранилища. Для переноса данных между ними нужен экспорт/импорт. Поддержка локальных HTML-файлов на телефонах зависит от ОС и браузера. Для доступа по ссылке требуется интернет; автономный режим опубликованной страницы при закрытии не гарантируется.

## Напоминания

Работают внутри открытой страницы; системные уведомления зависят от браузера и его разрешений. При закрытии страницы уведомления не гарантируются. После возвращения показываются пропущенные напоминания за текущий день. В примерах уведомления отключены.

## Файлы

- `index.html`, `style.css`, `script.js` — приложение без внешних библиотек.
- `concept.md` — концепция.
- `tz.md` — спецификация реализованной первой версии и сценарии использования.

На компьютере можно перетаскивать карточки между днями. На телефоне и с клавиатуры используйте «Перенести» и измените дату в форме.
