# Техническое задание: «Ритм недели», версия 1

## Основание и границы

Первая версия создаётся по concept.md. Пользователь разрешил принять предложенные настройки по умолчанию и опубликовать приложение на GitHub Pages. Этот документ конкретизирует фактический объём первой версии. При расхождении с концепцией приоритет имеет этот документ.

Три файла приложения: index.html, style.css, script.js. Нативные HTML, CSS, JavaScript; без сборки, внешних шрифтов, библиотек, API, серверной логики и базы данных. Документация хранится отдельными Markdown-файлами.

## Роли

| Участник | Возможности |
| --- | --- |
| Посетитель без профиля | Выбрать существующее имя или создать локальный профиль |
| Пользователь профиля | Управлять своими задачами, повторениями, выполнением, поиском, экспортом и импортом |
| Другой пользователь этого браузера | Выбрать любой локальный профиль; пароль отсутствует |
| Владелец репозитория | Управлять исходниками и публикацией через GitHub; внутри планировщика административной роли нет |

Ни общей базы задач, ни совместного редактирования, ни автоматического обмена между устройствами нет. Любой человек со ссылкой открывает приложение со своим браузерным хранилищем.

## Настройки по умолчанию

Русский интерфейс, светлая тема, понедельник — начало недели, время в формате 24 часа. Новая задача: время 09:00, категория «Дела», не выполнена, без повторения, напомнить за 15 минут. Название, дата и время обязательны. Даты допустимы в 2000–2099 годах. Название: 1–120 символов после удаления пробелов по краям. Имя: 1–40 символов, внутренние повторяющиеся пробелы сокращаются до одного. Совпадение имён без учёта регистра открывает существующий профиль.

## Экраны

Основной экран содержит профиль, включение системных уведомлений, заголовок, процент выполнения всей недели, переключение недель, возврат к текущей неделе, новую задачу, поиск, фильтры, переключатель «Все даты», семь дней, статистику категорий, пример недели, экспорт и импорт.

На широком экране дни расположены в семи колонках. При ширине до 760 px — вертикально, с переключателем для прокрутки к дню. Форма задачи и формы профиля/импорта — модальные dialog с доступными подписями. Карточки и кнопки доступны с клавиатуры. Текст пользователя выводится с экранированием HTML.

## Категории

Фиксированный набор: Дела (песочный), Работа (синий), Встречи (лавандовый), Движение (зелёный), Культура (терракотовый), Для себя (розовый). Категория отображается текстом и цветом. Создание/удаление категорий, переименование и удаление профилей в первую версию не входят.

## Функции и правила

### Задачи

Создание через общую кнопку или кнопку дня. Общая кнопка подставляет сегодняшнюю дату; кнопка дня — дату выбранного дня. После сохранения открывается неделя задачи. Карточка содержит время, название, категорию, выполнение, пометку повторения и действие переноса.

Нажатие названия или «Перенести» открывает форму. Дата и время меняются независимо. Завершённую задачу можно вернуть в запланированные; завершать будущие задачи разрешено. Выполненные задачи остаются видимыми, становятся бледнее, название зачёркивается. Просрочка вычисляется после времени начала для невыполненной задачи. Автоматического переноса нет.

При закрытии изменённой формы спрашивать о потере изменений. Удаление отдельной задачи предлагает отмену на 10 секунд. Удаление всей серии требует подтверждения. Отмена действует для того профиля, в котором произошло удаление.

### Перенос

На компьютере применяется HTML drag-and-drop между днями отображаемой недели; дата меняется, время сохраняется. Другую неделю можно указать в форме. На телефоне основной способ — кнопка «Перенести» и изменение даты. Touch-перетаскивание не является обязательным для версии 1. Внутри дня карточки сортируются по времени, затем по названию.

### Повторения

Варианты: без повтора, ежедневно, по выбранным дням недели. День недели кодируется 0–6 (понедельник–воскресенье). Минимум один день для недельного повтора. Дата начала включена только если подходит правилу; дата окончания включительна, необязательна и не раньше даты начала.

Правило серии хранится в одной записи. Для каждого появления используется ключ id@исходная-дата. Выполнение, перенос и удаление одного появления сохраняются как исключение по исходной дате. Перенос исключения сохраняет исходный ключ и новую дату отображения.

Редактирование существующей серии предлагает «Только к этой задаче» и «К серии (будущие невыполненные)». Для одной задачи можно изменить название, время, категорию, напоминание, дату и выполнение. В режиме серии меняются название, время, категория, напоминание, дни и окончание; существующие индивидуальные исключения сохраняют приоритет. Дата в форме переносит выбранное появление, не начало серии. Смена типа существующей серии запрещена: создать новую серию отдельно. Удаление всей серии удаляет историю и требует подтверждения. «Эту и последующие» отдельно не реализуется.

### Поиск и статистика

Поиск по подстроке названия без учёта регистра. Один фильтр категории; статус: все, запланированные, выполненные, просроченные. Запланированные включают просроченные. Фильтры объединяются логическим И.

Обычный поиск работает в выбранной неделе. «Все даты» показывает отдельный список с датами. Бесконечные серии ограничиваются годом до и после сегодня; диапазон расширяется до дат одиночных задач, конечных серий и перенесённых исключений. Об ограничении написать над результатами.

Статистика всей отображаемой недели не зависит от фильтров. Процент = округлённые выполненные / все задачи × 100. Пустая неделя — 0%. Удалённые появления не учитываются. Каждое появление серии учитывается отдельно. Для каждой непустой категории показывать выполнено/всего.

### Напоминания

Одно напоминание: выключено (-1), в момент начала (0), за 5, 15, 30, 60 минут. Проверка при запуске, сохранении, возвращении на вкладку и каждые 30 секунд, пока вкладка видима. Обязателен внутренний блок с названием, временем и кнопками открытия/закрытия.

Проверять сегодняшний и завтрашний день для напоминаний до полуночи. На возвращении показывать пропущенные напоминания сегодняшних задач, а не весь архив. Завершённые задачи не напоминают. Ключ доставки включает ключ появления, фактическую дату, время и смещение; повторная проверка не дублирует показ. Изменение времени или смещения создаёт новый ключ.

Системные уведомления запрашиваются только нажатием кнопки. Отказ или отсутствие API не блокируют внутренние напоминания. Закрытая страница, фоновые задержки и мобильные ограничения не позволяют обещать точную доставку. Service Worker, звук и откладывание уведомлений отсутствуют.

### Профили и хранение

Local Storage: ключ rhythm-week-v1. Корневой объект: version=1, active (id профиля или null), profiles[]. Профиль: id, name, tasks[], notified{}. Задача: id, title, date (YYYY-MM-DD), time (HH:mm), category (идентификатор), done (boolean), reminder (число), repeat {type, days[], until}, overrides {исходная-дата: изменения}. Даты и время локальные, без конвертации в UTC.

Сохранять после каждого подтверждённого изменения. При повреждённом хранилище не перезаписывать исходную строку автоматически: работать в памяти с сообщением и возможностью экспорта. При ошибке записи показывать сообщение. Изменения другой вкладки принимать через storage event после проверки формата.

### Резервные копии

Экспорт текущего профиля: JSON {version:1, profile}, файл rhythm-YYYY-MM-DD.json. Включает задачи, правила и исключения. Импорт: максимум 5 МБ и 10 000 записей, проверить версию, типы, даты, время, категории, повторения, исключения и уникальность идентификаторов задач до изменений.

Показать имя и количество задач/серий. Варианты: отдельный профиль с новым id и суффиксом при совпадении имени; замена текущего профиля с подтверждением. Уведомления после импорта начинаются с чистого журнала. Объединения задач нет. При ошибке исходный план остаётся неизменным.

## Сценарии использования

| Сценарий | Действия пользователя | Результат |
| --- | --- | --- |
| Первый запуск | Ввести имя, открыть план | Создан локальный профиль, показана пустая неделя |
| Вернуться в план | Открыть страницу в том же браузере | Восстановлены профиль и задачи |
| Сменить профиль | Нажать имя, выбрать другой профиль | Показан его план |
| Спланировать встречу | Добавить название, дату, время и категорию | Карточка в нужном дне, сохранение |
| Выполнить задачу | Поставить галочку | Зачёркивание и пересчёт статистики |
| Отменить выполнение | Снять галочку | Возврат обычного оформления |
| Перенести на другой день | Перетащить карточку на компьютере | Новая дата, прежнее время |
| Перенести на другую неделю | Открыть «Перенести», изменить дату | Показана неделя новой даты |
| Регулярно тренироваться | Выбрать недельный повтор и дни | Независимые появления одной серии |
| Перенести одну тренировку | Изменить дату, область «Только эта» | Создано исключение, остальные неизменны |
| Изменить расписание серии | Выбрать область серии, изменить настройки | Новые параметры с учётом исключений |
| Удалить и передумать | Удалить, нажать «Отменить» в течение 10 секунд | Восстановлены данные до удаления |
| Найти театр | Поиск по названию или фильтр «Культура» | Показаны совпадения |
| Найти за пределами недели | Включить «Все даты» | Список результатов с датами |
| Оценить неделю | Посмотреть круг и категории | Общая статистика независимо от фильтров |
| Получить напоминание | Держать страницу открытой | Внутреннее уведомление, системное при разрешении |
| Перенести данные на телефон | Экспорт на компьютере, импорт на телефоне | Локальная копия профиля на телефоне |
| Восстановить копию | Импорт, проверить сводку, выбрать режим | Новый профиль или замена подтверждённого |
| Посмотреть пример | Нажать «Пример недели», подтвердить | Шесть задач без напоминаний добавлены к текущим |

## Проверки приёмки

Проверить синтаксис JS; первый вход; добавление и редактирование; сохранение после перезагрузки; выполнение и обратную отметку; сортировку; перенос одиночной задачи и исключения серии между неделями; ежедневный и недельный повтор; фильтры и поиск; независимую статистику; уведомления и отсутствие дублей; отмену удаления; экспорт и импорт; отказ некорректному JSON; экранирование названий; мобильную ширину без горизонтальной прокрутки.

Проверить публикацию main / root в GitHub Pages и открытие публичного адреса с загрузкой CSS/JS. Пользовательские планы и файлы резервных копий в публичный репозиторий не загружать.
